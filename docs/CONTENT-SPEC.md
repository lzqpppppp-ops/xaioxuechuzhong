# 内容规范（知识点数据文件）

本项目是「小学 → 初中」备考网页，以**广西中考（全区统一命题）**为检验标准。
所有知识点和题目以 `data/parts/*.js` 静态 JS 文件存放（必须能 `file://` 双击打开，所以不用 JSON + fetch）。

## 文件格式（严格遵守）

每个 part 文件形如：

```js
window.CURRICULUM_PARTS = window.CURRICULUM_PARTS || {};
window.CURRICULUM_PARTS["math-primary"] = {
  subject: "math",
  points: [
    {
      id: "mp-001",
      grade: 1,
      title: "10以内数的认识与比较",
      difficulty: 1,
      minutes: 6,
      tag: "数与代数",
      prereq: [],
      explain: "第一行……\n- 要点一\n- 要点二\n最后一行……",
      example: {
        stem: "例题题干",
        steps: ["第一步……", "第二步……"],
        answer: "答案"
      },
      quiz: [
        { type: "choice", stem: "题干", options: ["A内容", "B内容", "C内容", "D内容"], answer: 1, why: "解析" },
        { type: "fill", stem: "3 + 5 = ____", answer: ["8"], why: "解析" }
      ]
    }
  ]
};
```

### 字段约束

- `id`：全站唯一。格式 `<part前缀>-<三位序号>`，如 `mp-001`、`mj-001`、`cp-001`、`cj-001`、`ep-001`、`ej-001`、`ph-001`、`ch-001`、`sw-001`、`dl-001`、`zz-001`、`ls-001`。
- `grade`：1–9 整数。小学 1–6，初中 7–9。必须与内容真实年级一致。
- `difficulty`：1–5，1 最简单。**同一 part 内按 grade 升序、同 grade 内由易到难排列**。
- `minutes`：预计学习分钟数，4–15。
- `tag`：2–6 字的知识板块名（如「数与代数」「文言文」「电学」）。
- `prereq`：前置知识点 id 数组，可为 `[]`；只引用同 part 内已出现的 id。
- `hint`（可选）：**25–60 字**，学生做题卡住时看的思路提示。只能指方法、看图角度、回忆哪条规律，**绝对不能直接给答案**。没有这个字段时，网页会用科目通用思路 + 讲解里的要点行兜底。
- `explain`：**150–350 字**中文讲解。面向学生、第二人称，先给生活化直觉或例子，再给规则/方法，最后一句易错提醒。换行用 `\n`；要点行以 `- ` 开头；可用 `**加粗**`。禁止 LaTeX、禁止 Markdown 表格、禁止 HTML。
- `example`：一道完整示范题，`steps` 2–5 步，每步一句话说清「为什么」。
- `quiz`：**3–5 题**，至少 1 道 `choice`、至少 1 道 `fill`。
  - `choice`：`options` 为 **2–4 个**，`answer` 是正确项下标。干扰项要像真错法（算错、概念混淆），不要凑数。
  - 判断题、比较大小这类二选一，一律用 `choice`，不要用填空（学生不用再输入 √ / × / >）：
    `{ type: "choice", options: ["正确（√）", "错误（×）"], answer: 0 }`、`{ type: "choice", options: [">", "<", "="], answer: 2 }`。
  - `fill`：`answer` 为**可接受答案数组**（如 `["12","十二"]`），答案里不要带单位（单位写进题干）。
  - `why`：25–80 字，讲清关键一步或错因，不要只重复答案。

### 质量硬要求

1. **零超纲、零错误**。数学计算必须自己验算；化学方程式必须配平；文言文注释必须准确。
2. 小学内容按**课标 + 小学毕业要求**，并点明与初中的衔接；初中内容对齐**广西中考考点与常见题型**（选择、填空、解答的基础问）。
3. 语言简洁口语化，不堆术语；每道题的解析要让做错的学生看懂「错在哪」。
4. 中文字符串里的双引号用中文引号「」或“”，避免转义地狱；必须用 `\"` 时确认转义正确。
5. **JS 文件必须语法合法**：写完后运行 `node --check data/parts/<文件>.js` 自查，报错就修到通过。

## 各 part 覆盖清单（不得遗漏，也不要重复）

### math-primary（36 点，subject: "math"）
一年级：10以内数的认识与比较；10以内加减法；20以内进位加法；认识图形与位置；认识钟表（整时半时）

四年级：大数的认识；三位数乘两位数；除数是两位数的除法；运算定律与简便计算；小数的意义与性质；三角形与四边形
五年级：小数乘法；小数除法；简易方程；多边形的面积；因数与倍数；分数的意义与性质；长方体和正方体

## 可视化（可选）

抽象的数学知识点可以配一张可交互的图，学生做题卡住时点「💡 提示」就能调出来。图和知识点的对应关系写在 `assets/js/viz-map.js`，**不需要改数据文件**：

```js
var BY_ID = { "mj-018": { key: "function", type: "linear" } };
```

现有图形：`numberline`（数轴）、`cube`（正方体 + 展开图）、`function`（一次/二次/反比例）、`views`（三视图，点格子加高）、`circle`（弧长/扇形/圆周角）、`rotation`（旋转）。

给新的知识点配图：在 `viz-map.js` 的 `BY_ID` 里加一行 `知识点 id → { key, type }`，再在 `EXTRA_HINT` 里写一句针对性的提示语即可。没有图的理科题，提示会自动退化成该知识点讲解里的要点清单。
