# 中考通关 · 小学到初中每日学习网页

一个可以离线使用的学习网页：知识点从小学到初中由易到难排列，每天自动生成一组任务（新学 + 复习 + 错题），学完立刻判题、给反馈、记掌握度，进度存在本机浏览器里。
内容按**广西中考（全区统一命题）**的知识范围编排；中考页提供分值、等级说明和模拟考，用来检验学到什么程度（不含历年真题原卷）。

## 打开方式

- **双击 `index.html`** 就能用（推荐，纯离线，不需要联网、不需要安装任何东西）。
- 首次打开会有 30 秒设置：昵称、现在读几年级、每天能学多久。设置完直接生成今天的任务。
- 如果浏览器对本地文件限制较多（进度存不住），双击 **`启动本地服务器.bat`**，它会用本机 Python 起一个本地服务并自动打开网页。
- 换电脑、重装浏览器之前，去「设置 → 数据备份」导出进度文件，新环境里再导入。

## 每天怎么用

1. 打开「今日」，看到今天的 **新学 3 个 + 复习若干 + 错题重练**。
2. 点任意一条开始：**讲解 → 例题 → 练习 → 结算**。练习逐题判定，答对撒花、答错当场给解析。
3. 结算页会告诉这次加了多少经验、掌握度从多少到多少、几天后该复习（间隔复习：答得好间隔翻倍，答错第二天再来）。
4. 想多学：去「知识地图」按科目/年级挑，锁住的点可以「提前解锁」。
5. 每周做一次「中考」里的模拟卷（10 题、15 分钟），按正确率换成 A+ 到 E 的等级。
6. 「错题本」收知识点练习里答错的题，可一键重练；答对一次就自动移出。

### 抽象图形的「动手看」

- 数轴、正方体、函数图象、三视图、圆、旋转，加上物理的「光的折射」和地理的「地球公转」，共 8 个知识点在讲解里直接内嵌**可交互的图**：拖圆点、拖滑块、转立方体、点俯视图加高、拖入射光、沿轨道拖地球，图上的数字和公式实时跟着变。
- 「实验室」页把这 8 个图放在一起，可以随便玩。
- 做题卡住时，每道题右上角都有 **💡 提示**：有图的直接调出动态图；没图的按科目给出「怎么想 + 本课要点」（物理先画图列公式、化学先判反应类型、历史先定时间、地理按位置—地形—气候链条、生物按结构—功能—过程……），只给思路不给答案。
- 判断题、比较大小的题已经改成**点选**（「正确（√）/ 错误（×）」「> / < / =」），不用再输入符号。

### 成长林（思维导图树）

- 每个「科目 × 年级」是一棵树，共 38 棵；**学完一个知识点（做完一节课的练习）就长一片浅绿的新叶**，掌握度到 80% 叶子变深，整章全部掌握这棵树才**成树结果**，卡片挂上金星。
- 结算页会直接告诉你「成长林：数学 7 年级 已长 3/9 片叶，还差 6 片 →」，点一下就能去看树；第一次学还会弹一句「长出一片新叶」。
- 树有 4 种造型（阔叶、松树、柳树、花树），颜色跟科目走；点任意一棵树，会展开这一章的**思维导图**：根节点 → 各知识点分支，标出每片的掌握度，可以直接「学下一课」。
- 季节（春/夏/秋/冬）按真实月份自动切换，也可以在页面右上角手动选：春天花瓣、夏天光点、秋天落叶、冬天飘雪，冬天的树冠还会积雪。
- 「园丁建议」会挑出离成树最近的一章，一键跳过去；林子里还藏了小彩蛋（小鸟、四叶草、蜜蜂、蝴蝶……），每天每种只奖励一次。

- 每个知识点都有：150–350 字讲解、一道分步例题、3–5 道练习（选择 + 填空），每题带解析；选择为 2–4 个选项，判断题和比较大小的题直接点选。
- 小学部分按小学毕业要求，并点明和初中的衔接；初中部分对齐广西中考的常见考法。
- 中考事实（2025 年方案）：语文/数学/英语各 120 分（英语听力 30 分）、物理/化学各 100 分、道德与法治/历史各 75 分、体育 60 分，八年级地理+生物折算 60 分，总分 830；九科全区统一命题；成绩按 A+、A、B+、B、C+、C、D、E 八等呈现。2026 年以自治区和各市当年文件为准。

## 进度存在哪

- 存在浏览器 `localStorage` 的 `zk.learn.v1` 里，**只在这台电脑的这个浏览器里**。
- 清浏览器数据、换浏览器、用无痕模式都会丢失，所以定期「导出进度文件」（一个 JSON）做备份。
- 网页本身不联网、不上传任何数据。

```

  util.js                  日期、富文本、答案判定、提示与音效

  viz.js                   6 个可交互图形（canvas / CSS 3D）
  viz-map.js               知识点 → 图形映射 + 提示语
  hint-map.js              各科「怎么想」提示规则 + 单点提示
  forest.js                成长林：树形图、物种、季节、粒子
  view-home.js             今日
  view-map.js              知识地图
  view-learn.js            讲解→例题→练习→结算
  view-forest.js           成长林页面 + 章节思维导图
  view-more.js             实验室 / 错题本 / 中考 / 数据 / 设置 / 首次引导
  app.js                   路由、事件、计时
data/parts/*.js            知识点数据（按科目分文件；页面按需懒加载，校验/工具仍可一次全载）
docs/CONTENT-SPEC.md       内容格式规范（想加知识点看这个）
tools/validate.js          内容与引擎自检：node tools/validate.js
tools/migrate-judge.js     把「填 √ 或 ×」的判断题批量改成选择题（--write 才写入）

tools/shot.html            截图用（带演示进度）
```

## 想加知识点 / 改题目

1. 打开 `docs/CONTENT-SPEC.md`，照着字段写。
2. 在 `data/parts/` 里找到对应科目的文件，追加一个对象到 `points` 数组（`id` 不能重复）。
3. 跑 `node tools/validate.js`，它会检查 id、年级、选项、答案、解析等，报错就按提示改。
4. 刷新网页即可看到，不需要构建、不需要装依赖。

- 内容用于学习参考，题目难度和表述尽量贴近中考，但不保证覆盖所有年份的地方差异。
- 浏览器要求：Chrome / Edge / Firefox 近几年的版本（用到 `details`、CSS 变量、`localStorage`）。
